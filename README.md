# 巴尔干旅行手册 · 摄影资产本地化版

解压后打开 index.html，保持 assets 文件夹相邻。

- index.html：文件夹版，样式内嵌，9张替换照片使用 assets/photos/ 本地路径；其他已有照片仍按原方式内嵌。
- offline.html：完整单文件版；封面、照片、地图、手绘图标、样式均内嵌，可单独复制。
- page-template.html / theme.css：可编辑源文件；运行 python3 build.py 同时更新两个成品。
- review/photo-localization/图片资产清单.md：本轮审计、点位对应文件、作者许可、验证结果与未完成测试说明。
- review/photo-localization/assets.json：新照片来源、尺寸、大小与校验值。
- review 内其他目录为此前视觉升级的历史审计，不代表本轮离线测试结果。

本轮仅替换9张远程点位照片及相应出处/alt。行程正文、顺序、导航、展开逻辑、日期切换、倒计时、勾选和存储脚本未改变。

注意：所有图片依赖已本地化并成功解码；浏览器实际断网展开和微信实机测试因环境限制尚未完成。云浏览器安全策略拒绝打开本地文件，详情见本轮报告。

底部导航：航班 / 行程 / 预定 / 清单。
勾选和备忘沿用原 localStorage 逻辑，数据取决于浏览器和访问地址；两个文件不会自动共享进度。外部地图、酒店网站等跳转仍需网络。
