审计基线：用户提供 ZIP 内的 index.html、page-template.html、theme.css、build.py、README.md 与摄影资源。先读取脚本和全部样式，再检查渲染。

## 结构与样式债务

- 七个一级章节均已有 chapter-opening：航班机票、行程总览、每日行程、住宿预订、SIXT 自驾租车、行前准备、行装指南。原始代码不是缺少色带，而是色带规则与其他历史层叠共存。
- 模板含 8 个 style 块（621 个规则/条件块），外置主题另有 331 个规则/条件块。包括 point-detail、schedule、estimated-day、minimal-expander、taste-refresh、cover-v4、piva-theme 等历史层。旧 schedule / point-card 等已无对应 DOM。
- 一级 H2 最终为 29px、650、宋体栈，章节色带最小高度 148px；摘要 13px。桌面摘要又被靠右显示，破坏标题下方的连续阅读。
- Day H2 最终为 24px、650、无背景；点位 H3 为 16px；酒店强标题和车型 17px；模块 H3 为 18px；详情 H4 为 13px。
- 城市轨迹、准备分类、取还车标题、行装分类由 ::before 生成短横线。正文使用无衬线，一级章节仍用宋体。
- .pill 出现在封面与租车摘要，最终已无背景；stop-duration 多次经历背景添加与移除。strong/b 最终主要为透明，但此前存在大量组件级样式。
- 当前正文、酒店记录、租车和城市轨迹大多透明；封面、航班对象有底色，背景层次不足。早期面板、点位、fact 卡片套卡片规则仍留在源码。
- 外链已采用本地同族 1.7px 线性 SVG mask；33 个图片 onerror 文案仍带 ↗。依据“所有 JavaScript 保持”约束，事件处理器原样保留，在报告中明确这一失败状态例外。
- 详情照片已有最终 16:10 / cover / 14px 规则，之前仍保留 contain、最大高度、9/10/15px 圆角覆盖。路线图是完整纵向地图，应保持原比例避免裁掉信息。
- 每日同一住宿照片、多日同一餐厅内容属于实际行程复用，保留。仅移除未使用和冲突样式，不删行程正文。
- 实际底栏是“航班 / 行程 / 预定 / 清单”四项；本次按用户明确要求改为“行程 / 住宿 / 地图 / 清单 / 更多”，航班和租车等入口放入更多。
