# 一级章节旅行速写升级

本次遵循 design-taste-frontend，参数 7 / 3 / 5。仅修改七个一级章节的 CSS，添加七枚本地透明 PNG 图标。HTML 模板经 SHA-256 与逐字节比较完全一致，因此文字、结构、数据、锚点、链接、摄影资产及四段 JavaScript 均未修改。

修改前：七章统一采用 128px 浅绿矩形色带。移动端标题29px，桌面30px。相邻内容审计见 before-audit.json。

修改后：取消大色带；保留标题字号、普通字重摘要；使用64px手绘图标、留白和细分隔线。航班／每日行程／行装指南为图标在上，其余为左图右文。七章共享排版语法，保持两种轻量构图。

图标由一次图像生成制作统一透明图集，再按网格机械分割和导出为512×512 RGBA PNG；未重绘、替换现有旅行照片。资产位于 assets/chapter-icons，分别对应章节ID。通过 CSS 装饰伪元素加载，不改变 DOM 或屏幕阅读器内容。

已检查全部七章390px截图、1280px桌面截图、透明背景与图标路径、横向溢出及脚本错误。测试结果见 browser-check.json，七章一览见 chapters-preview.png。四项导航与存储回归见 navigation-check.json。

运行：解压后打开 index.html；图标文件夹须与HTML一起保留。编辑 theme.css 后运行 python build.py 重建 index.html。
